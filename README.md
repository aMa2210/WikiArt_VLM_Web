This repository contains the results of analyzing a set of original and AI-generated paintings using various Vision-Language Models (VLMs), as well as a visualization website built on top of these results.

## Repository Structure

- `Script/Results{model name}`: Contains outputs from several VLMs applied to the image dataset generated by {model name}. Two types of prompts were used:
  - "Is this a real painting from <correct painter>? Please answer only yes or no."
  - "Is this a real painting from <random painter>? Please answer only yes or no."
- `index.html, script.js, style.css`: Source code for a visualization [website](https://ama2210.github.io/WikiArt_VLM_Web/) that allows users to explore the VLM analysis results interactively.
- `.json files`: Aggregated results derived from the VLM responses.
